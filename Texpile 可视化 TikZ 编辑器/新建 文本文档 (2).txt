### 先启动服务（必须步骤，禁止直接双击打开）

直接双击用 `file://` 打开会导致拖拽导入、Blob 下载等功能异常，必须走静态 HTTP 服务：

1. 打开 PowerShell，进入文件所在目录：
```
cd "C:\Users\86159\Desktop\Texpile 可视化 TikZ 编辑器"
```
2. 启动静态服务器：
```
python -m http.server 8766
```
3. 浏览器打开地址：
```
http://127.0.0.1:8766/editor.html
```

### 二、手动逐项测试（核心功能验证）

按以下步骤操作，即可验证全部核心能力：

#### 1. 基础界面检查

- 预期：页面显示三栏布局
  - 左栏 200px：Pages 面板，显示 `p.000.w1h1` 单页占位
  - 中间：顶部工具栏 4 个按钮 + 白色画布，带浅灰色 100px 网格
  - 右栏 260px：Inspector 面板，默认显示「请选择画布元素」
- 预期：画布内有左右两个蓝色描边矩形，对应 `leftText`（左）和 `rightScene`（右）

#### 2. 选中与控制点测试

- 操作：点击左侧的 `leftText` 矩形
- 预期：
  - 矩形描边变粗 / 加深（选中态）
  - 矩形四角 + 四边中点，共出现 8 个白色小圆控制点
  - 右侧 Inspector 自动显示 X、Y、Width、Height 四个数值，和矩形坐标一致

#### 3. 拖拽移动测试

- 操作：按住矩形主体，向右下方拖动一段距离松开
- 预期：
  - 矩形跟随鼠标移动，不会超出画布边界
  - 右侧 Inspector 的 X、Y 数值实时变化
  - 松开后数值为整数，位置稳定不回弹

#### 4. 缩放手柄测试

- 操作：按住右下角的控制点，向外拖动放大
- 预期：
  - 矩形宽高同步变大，左上角位置不动
  - Inspector 的 Width、Height 实时增加
- 进阶测试：按住 `Shift` 键拖拽右下角控制点，矩形会保持宽高比等比缩放

#### 5. Inspector 双向同步测试

- 操作：在 Inspector 的 X 输入框里输入 `200`，按回车
- 预期：画布上的矩形立刻向右移动到 X=200 的位置
- 边界测试：输入 `-100`，失焦后会自动修正为 `0`，矩形贴紧左边界

#### 6. 视口缩放测试

- 操作：鼠标放在画布上，滚动滚轮
- 预期：画布整体放大 / 缩小，但矩形的坐标数值不变；缩放范围 25%~200%
- 操作：点击顶部「适配窗口」按钮
- 预期：画布自动缩放到刚好完整显示在视口内，四周留边

#### 7. 导出功能测试

- 操作：点击顶部「导出 JSON」按钮
- 预期：浏览器自动下载 `p.000.w1h1.json` 文件
- 验证：用记事本打开，结构只有 `pageId`、`canvas`、`regions` 三部分，没有多余字段

#### 8. 导入功能测试

- 操作：把刚才导出的 JSON 文件，直接拖拽到画布区域
- 预期：画布自动加载文件里的坐标，矩形位置和导出时完全一致

### 三、与 manifest.json 兼容性测试（联调验证）

验证导出的单页 JSON 可以直接给 8765 预览端使用：

1. 打开导出的 `p.000.w1h1.json`，全选复制里面的内容
2. 打开你的 `manifest.json`，找到 `pages` 数组里对应页面的对象
3. 把复制的内容直接替换掉原页面对象（`pageId` 对应上即可）
4. 刷新 8765 预览页

- 预期：页面布局、区域位置和编辑器里完全一致，无需任何二次转换
